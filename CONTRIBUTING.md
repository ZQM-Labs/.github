# Contributing to ZQM Labs

Thank you for your interest in contributing to ZQM Labs — Z's Quests & Mischief!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes (`git commit -m 'Add your feature'`)
4. Push to the branch (`git push origin feature/your-feature`)
5. Open a Pull Request

## Code Standards

- Follow existing code style
- Add tests for new features
- Update documentation as needed
- Keep commits atomic and descriptive
- All repos are MIT-licensed unless otherwise noted

## Reporting Issues

- Use GitHub Issues for bug reports
- Include steps to reproduce
- Specify your environment (OS, version, etc)
- For security vulnerabilities, see [SECURITY.md](SECURITY.md)

## Quest Content

- Game content (quests, stories, characters) is CC-BY-4.0
- Commercial contributors retain copyright; commercial rights remain with ZQM
- No harassment, discrimination, or hostile behavior
- No disclosure of private buyer data or keys
- No adversarial changes to evidence or provenance artifacts

## Questions?

Open an issue or discussion in the repository.
