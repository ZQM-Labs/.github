# ZQM Labs — Z's Quests & Mischief

**Games, gear & a little mischief.** Location-based scavenger-hunt games for neighborhoods, schools, churches, scout troops, and office parties across Volusia County, Florida.

- **Location quests** — self-guided QR scavenger hunts, a new edition every season (first up: Halloween). Set the Dial: Cozy Glow -> Spooky -> After Dark -> Full Madness.
- **Gamification engine** — leaderboards, achievements, XP, and streaks. The portal tracks engagement and rewards exploration.
- **Party gear rentals** — coming soon.

## ZQM Computing — the geospatial arm

[ZQM Computing](https://github.com/ZQM-Computing) is the geospatial engineering arm of ZQM Labs. They build the patterns, data infrastructure, and tooling that ground our games in real-world locations:

- **[geospatial-patterns](https://github.com/ZQM-Computing/geospatial-patterns)** — umbrella index of all 14+ geospatial repos
- **[zqm-labs](https://github.com/ZQM-Computing/zqm-labs)** — games monorepo (player PWA, PocketBase, Hugo site)
- **[postgis-patterns](https://github.com/ZQM-Computing/postgis-patterns)** — production PostGIS patterns
- **[geopandas-patterns](https://github.com/ZQM-Computing/geopandas-patterns)** — GeoPandas patterns for game design
- **[h3-patterns](https://github.com/ZQM-Computing/h3-patterns)** — H3 hexagonal grid for location binning
