# ZQM Labs — Z's Quests & Mischief 🎃
**Games, gear & a little mischief.** Location-based scavenger-hunt games for neighborhoods, schools, churches, scout troops, and office parties across Volusia County, Florida.

- 🎃 **The Lantern Games** — self-guided QR scavenger hunts. Set the Dial: Cozy Glow → Spooky → After Dark → Full Madness.
- 🗺️ **Project Volusia** — the open data portal for Volusia County.

Repos here are the Lab's workbench — games, data, and the tools that build both.
